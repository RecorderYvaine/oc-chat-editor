# 聊天记录编辑器

一个完全在浏览器中运行的微信、QQ、iMessage 模拟聊天记录编辑器，适合制作手机聊天截图和捡手机文学素材。

## 使用

直接打开 `chat-editor.html`，或访问 GitHub Pages 首页。编辑器支持多个聊天场景、群聊和私聊、全局角色管理、消息排序、消息引用、图片与表情上传、红包、转账、通话、定位、文件、撤回通知、语音转文字，以及单页 PNG、连续截图和完整长图导出。

点击“接入本地文件夹”后，选择一个本地文件夹，编辑器会把完整项目（所有聊天场景、角色、消息、设置和上传资源）持续写入其中的 `chat-editor-project.json`。没有授权时会自动使用浏览器本地保存。也可以使用“导出项目”和“导入项目”在 ZIP 项目文件与设备之间迁移数据。

本地文件夹授权使用浏览器的 File System Access API，需要最新版 Chrome 或 Edge。网页不需要服务器账户，也不会把项目数据上传到服务器。

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。使用本地文件夹授权时，建议通过 `localhost` 或 HTTPS 访问。

## 许可证

编辑器代码与素材随本项目发布；`vendor/` 中的第三方库按照各自许可证使用。
